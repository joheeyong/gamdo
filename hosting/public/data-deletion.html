감도 데이터 삭제 안내

삭제 요청이 처리되었습니다. 확인 코드:

감도는 인스타그램 연결로 받은 데이터를 다음 방법으로 언제든 삭제할 수 있습니다. 아래 어느 방법으로든 요청하면 감도 서버에 저장된 대표 사진과 클라우드(Firebase)에 저장된 스타일 프로필·보정 피드백이 삭제됩니다.

1. 앱에서 삭제

감도 앱 → 프로필(설정) → Instagram 연결 해제를 누르면 연결이 끊기면서 위 데이터가 함께 삭제됩니다.

2. 인스타그램에서 삭제

인스타그램 앱 → 설정 → 웹사이트 권한 → 앱 및 웹사이트에서 감도를 삭제하면, Meta가 감도에 알리고 감도는 해당 계정의 데이터를 삭제합니다.

3. 이메일로 요청

[연락처 이메일]로 인스타그램 사용자 이름과 함께 삭제를 요청하면 7일 안에 처리하고 회신합니다.

휴대폰에 남는 데이터

보정한 사진과 분석 기록은 사용자의 휴대폰 안에만 저장됩니다. 앱을 삭제하면 함께 지워집니다.

Data Deletion (English)

You can delete the data Gamdo received through Instagram at any time: (1) in the app, Profile → Disconnect Instagram; (2) in Instagram, Settings → Website permissions → Apps and websites → remove Gamdo; or (3) email [contact email]. Any of these deletes the reference photos stored on Gamdo's server and the style profile and feedback stored in Firebase. Edited photos and analysis history stay only on your phone and are removed when you uninstall the app.
